# Send Worldwide

## TikTok Product Feature Prototype

Send Worldwide is a proposed TikTok feature concept.

The idea is simple:

1. A creator selects a video.
2. The creator clicks SEND WORLDWIDE.
3. There is no recipient-selection screen.
4. The system automatically distributes the video to the accounts covered by the feature.
5. The dashboard shows account IDs, names, and delivery status.
